# Higher-Level Programming

ALU Software Engineering projects covering Python fundamentals, including
data structures (lists, tuples), exceptions, and shell scripting exercises
.
- python-more_data_structures: sets, dictionaries, lambda/map basics, and a Roman numeral converter
- python-exceptions: try/except/finally, raising built-in exceptions, safe printing patterns
- python-network_0: Bash scripts using curl to inspect HTTP responses (body size, body, methods, headers, POST params)
- python-network_1: Python scripts using urllib and requests to fetch URLs, read headers, POST data, handle errors, parse JSON, and authenticate with the GitHub API
- python-almost_a_circle: Base/Rectangle/Square class hierarchy covering private attributes, getters/setters, inheritance, *args/**kwargs, unit testing, and JSON serialization
