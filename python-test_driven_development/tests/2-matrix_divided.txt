The ``2-matrix_divided`` module
=================================

Import the function::

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Dividing a simple matrix of integers::

    >>> matrix = [
    ...     [1, 2, 3],
    ...     [4, 5, 6]
    ... ]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The original matrix is left untouched::

    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Dividing a matrix that mixes integers and floats::

    >>> matrix_divided([[1.5, 2.5], [3.5, 4.5]], 2)
    [[0.75, 1.25], [1.75, 2.25]]

A single row matrix::

    >>> matrix_divided([[1, 2, 3]], 2)
    [[0.5, 1.0, 1.5]]

Dividing by a float::

    >>> matrix_divided([[10, 20]], 2.5)
    [[4.0, 8.0]]

Dividing by a negative number::

    >>> matrix_divided([[10, -20]], -2)
    [[-5.0, 10.0]]
